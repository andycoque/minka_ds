The layer to build against. 234 tokens, each naming a job rather than a value:
`--color-bg-raised`, not `--primitive-neutral-0`. A theme redefines these and nothing
else, which is why one switch restyles every component.

Reach past them to a [primitive](/docs/tokens/primitives) only when what you are
styling carries no meaning worth naming.

Every swatch below resolves its own variable at paint time, so this page cannot go
stale. A token showing **not defined** is referenced but missing from the layer this
app imports.

## Do and don't

<DoDont>
  <Rule>
    <Do example={<span className="[border-radius:var(--radius-card)] border border-[var(--color-border-default)] bg-[var(--color-bg-raised)] px-3 py-2 text-body-sm">Semantic</span>}>
      Name the job: `--color-bg-raised`, `--radius-card`. It themes, and it says why
      the value was chosen.
    </Do>
    <Dont example={<span className="rounded-lg border border-neutral-200 bg-white px-3 py-2 text-body-sm">Raw</span>}>
      Reach for a raw Tailwind utility or a hex value. It cannot theme and it drifts
      from everything around it.
    </Dont>
  </Rule>
  <Rule>
    <Do example={<span className="text-body-sm text-[var(--color-text-muted)]">A muted description</span>}>
      Use a text token for ink, so dark mode inverts with the rest of the page.
    </Do>
    <Dont example={<span className="text-body-sm" style={{ color: '#6b7280' }}>A muted description</span>}>
      Hardcode a grey. It stays that grey on a dark ground, where it is unreadable.
    </Dont>
  </Rule>
</DoDont>
