The value layer: 215 tokens holding colour ramps, the type scale, radii, spacing,
shadows and z-indices, with no opinion about use.

Build against a [semantic token](/docs/tokens/semantics) instead. Name a primitive
directly only when what you are styling has no meaning to name, such as a decorative
stripe or a diagram fill, because a primitive cannot follow a theme.

### Type

Thirty-nine utilities. The scale itself is primitives; what you write in a component is
a **utility class**, not a token, which is why these are classes rather than
`var(--...)` references.

Every row below renders in its own class and reports the size it actually resolves to,
so this table cannot drift from the CSS.

**Serif is for titles, sans for everything else.** A `-serif` utility exists at nearly
every size because a section title and a page title are both serif at different scales,
not because serif is a choice you make per element.

#### Headings

Serif in practice.

**The `-lg-serif` set is a problem worth naming.** Each is one step larger than its
base, which means three of the four duplicate a value that already exists under another
name:

| Value | Names |
| --- | --- |
| 1.5rem | `heading-3-serif`, `heading-4-lg-serif` |
| 1.875rem | `heading-2-serif`, `heading-3-lg-serif` |
| 2.25rem | `heading-1-serif`, `heading-2-lg-serif` |
| 3rem | `heading-1-lg-serif` — the only one with no twin |

Usage backs that up: across the product, `heading-1-lg-serif` is used **once** (the login
brand panel) and the other three `-lg-serif` headings are used **nowhere**. Two names for
one value is a coin flip at every call site, and coin flips are how a type scale drifts.

Left in place for now rather than removed, because the login panel does need a 3rem
title. The honest fix is one `display`-scale serif for that case and dropping the other
three.

### Spacing, radius, z

Ten spacing steps, eight radii and eight z-levels sit under the semantic names above.
Use the semantic token: `--radius-card` rather than `--primitive-radius-lg`, so a
change to card rounding is one edit rather than a search.
