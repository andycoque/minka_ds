## Anatomy

<KbdDemo />

One key per `Kbd`. A shortcut is several of them in a row rather than one carrying
`⌘K`, so the reader sees two keys and presses two keys.

## Use something else when

- **It is a code or an identifier.** Inline code, or `DataCell` in a table. `Kbd`
  says "press this".
- **It is a menu shortcut hint.** `DropdownMenuShortcut`, which aligns it to the
  right of the item for you.

## Do and don't

<DoDont>
  <Rule>
    <Do example={<span className="flex items-center gap-1.5"><Kbd>⌘</Kbd><Kbd>K</Kbd></span>}>
      One key per `Kbd`, side by side.
    </Do>
    <Dont example={<Kbd>⌘K</Kbd>}>
      Put a whole shortcut in one. It reads as a single key that does not exist.
    </Dont>
  </Rule>
</DoDont>
