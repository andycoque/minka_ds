## Anatomy

<AvatarDemo />

Pass `name` and the initials are derived from it. `name` also becomes the alt text,
so it is worth passing even when there is a `src`.

Initials are set in the serif face, which is deliberate: an avatar is an identity
mark rather than UI text, and the display face reads as a monogram.

## Sizes

Switchable on the Anatomy panel above, since the size is the only thing that really
varies about an avatar.

| Size | Px | Use |
| --- | --- | --- |
| `sm` | 28 | Inline in a table row or a menu item |
| `md` | 36 | The default |
| `lg` | 48 | A detail page or a profile panel |

The product uses `sm` and `lg`. `md` is the component's default but nothing passes it
today, so it arrives by omission rather than by choice.

## Use something else when

- **It stands for a status.** `StatusCell`. A coloured circle beside a name is a
  status, and it should read as one.
- **It is a logo rather than a person.** Use the mark directly. Initials imply
  something with a name that could have had a photo.

## Do and don't

<DoDont>
  <Rule>
    <Do>
      Pass `name` even when you pass `src`, so the image has alt text and the
      fallback has initials.
    </Do>
    <Dont>
      Pass only `src`. A broken or slow image then leaves an empty circle with no
      accessible name.
    </Dont>
  </Rule>
</DoDont>

## Props

<PropsTable>
  <Prop name="name" type="string">
    Full name. Alt text, and the source of the initials.
  </Prop>
  <Prop name="src" type="string">
    Image URL. Falls back to initials when absent or broken.
  </Prop>
  <Prop name="initials" type="string">
    Overrides the derived initials, for a name that abbreviates oddly.
  </Prop>
  <Prop name="size" type="'sm' | 'md' | 'lg'" default="'md'">
    See [Sizes](#sizes).
  </Prop>
  <Prop name="background / color" type="string">
    Overrides the generated colours, for a participant with brand colours of its
    own.
  </Prop>
</PropsTable>
