# WOP

Minka's design system — a component library and playground built with Next.js, Tailwind CSS v4, and shadcn/ui. It implements a two-layer token architecture (primitives → semantic) and a set of tokenized UI components for use across Minka's product.

## Playground

Live at [minka-product-ui.vercel.app/design-system](https://minka-product-ui.vercel.app/design-system)

## Stack

- Next.js 16 (App Router, Turbopack)
- Tailwind CSS v4
- shadcn/ui components
- PP Neue Montreal typeface

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000/design-system](http://localhost:3000/design-system) to browse the component playground.
